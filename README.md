### Just Bookmark It!

Currently developing an API for aiding users to store and delete important hyperlinks. I have built a CI/CD pipeline using Github Actions Workflow for effective development and deployment of code. <br/>
TechStack Used: JavaScript, NestJS, Docker, Github Actions, AWS, PostgreSQL.

#### Clone Project

If you are looking for cloning this project, make sure you have Docker desktop installed on your machine because docker containers will require it for running and an AWS account having container registry set up<br/>
Apart from this, I have used PostgreSQL image version@14.5. You can pull the official docker image from Docker Hub

#### .ENV Example

DATABASE_URL=YOUR_DATABASE_URL<br/>
JWT_SECRET=YOUR_SECRET<br/>

POSTGRES_USER=YOUR_POSTGRES_USER<br/>
